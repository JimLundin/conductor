Rules the structure doesn't show

  • Every session belongs to an issue. A quick, unplanned session gets an issue made for it.
  • A session's instance runs on the node where its issue's branch is checked out.
  • Continuing on another instance or node is another session on the same issue; it works from the branch and the issue's notes, not from an earlier transcript.
  • An issue's checkout runs one turn at a time, and is cleaned when the issue closes or after seven idle days, keeping the branch.
  • The home never records where a node keeps a checkout; a node finds its checkouts by root commit and remote.
