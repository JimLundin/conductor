Conductor session model

Session

A conversation with one agent account on one host. Each session has its own ID, workspace and transcript.

Start in a Git directory, choose a project, or open an issue. The host takes a snapshot of the workspace before the agent starts and after each turn.

Project

A repository you work in. A project start uses a checkout on the chosen host. You can work in the project without opening an issue.

Issue

A piece of work in a project. Starting on an issue gives the agent its brief and branch. Its notes and published branch let another session pick up the work on a different host.

Host setup
Pairing
Pair a device with a host to see its sessions and send it commands.
Agent accounts
Each host runs the provider CLI with the selected account's credentials. Available accounts and models can differ between hosts.
Checkout paths
Each host finds its local copies of projects. A session gets an isolated worktree from a checkout.
