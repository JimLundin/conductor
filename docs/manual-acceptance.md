# Conductor hands-on checks

## Continue and Finish

Use a prepared session in a disposable project. After a prepared host
restart, select **Continue** and send a follow-up about the earlier
conversation. It should retain the conversation and workspace. The
original checkout should remain unchanged.

For a session on an issue, select **Finish** and check the transcript's
finished row: the commits landed and whether they were pushed. Check the
reported push result before continuing the issue on another host.

Turn diffs, removing a session, checklists and sign-ins are not in the
thin app (architecture §8); their checks return with the screens.

## The thin app on the iPhone

On mobile data, with two prepared hosts, each printing its join link and
ticket:

| Step | Your part on the iPhone |
| --- | --- |
| Install | Open the app from Pages in Safari and add it to the Home Screen. Open it from there. |
| Pair by join link | Open the first host's join link. The host appears in the list under its name and reaches **Live**. |
| Pair by ticket | Tap **Hosts**, paste the second host's ticket and tap **Pair**. Both hosts are listed, each with its link state. |
| Start a session | On each host, tap **New session**, choose an agent and a project or directory, and tap **Start**. The session opens and shows in its host's list. |
| Send | Send a message. The reply streams into the transcript. |
| Approve | Ask for a change that needs approval. Tap **Approve** on the request; it shows as approved and the tool card runs. |
| Answer | Ask the agent to ask you a question. Pick an option and tap **Answer**; it shows as answered. |
| Interrupt | Start a long turn and tap **Stop**. The turn shows as interrupted. |
| Continue | After a prepared host restart closes the session, tap **Continue** and send a follow-up. |
| Finish | In a session on an issue, tap **Finish**. The transcript shows what landed and whether it was pushed. |
| Forget | Tap **Hosts**, then **Forget** on one host. Its sessions leave the list, and the other host's remain. |

The agent prepares the hosts and sessions, runs the four-day and day-nine
checks, and records the results.
