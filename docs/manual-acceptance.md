# Conductor hands-on checks

## Start with Claude sign-in

Have your iPhone and a disposable Claude account ready. The agent starts both sign-in flows on WSL. The Mac can wait.

1. When the test runner shows the **setup-token** link, open it on your phone, approve it, and enter the returned code in the private test prompt.
2. Repeat for the **Claude login** link. If either flow gets stuck, say which one and where.

That finishes the first sitting. Keep codes and tokens out of chat.

## Later, when each feature is ready

| Feature | Your part on the iPhone |
| --- | --- |
| Phone sign-in | Approve the disposable Claude or ChatGPT sign-in when prompted. |
| Notifications | In the Home Screen app, enable notifications and lock the phone. Tap the test notification and confirm it opens the session with the pending request. |
| Two hosts | Tap **Add host** for the prepared Mac. Once session movement is ready, move the prepared session there and send one follow-up from the phone. |
| Tasks and subagents | Hand the prepared Claude task to Codex and check that it finishes. Open the prepared child sessions to see their progress and results. |

The agent prepares the hosts and sessions, runs the four-day and day-nine checks, and records the results.
